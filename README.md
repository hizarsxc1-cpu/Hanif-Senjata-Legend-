# H Legendary Weapons

A Minecraft Java 1.21 Fabric mod project.

## First development milestone

- Inferno Blade
- Seven configurable skill keybinds (default: Z, X, C, V, B, N, M)
- Survival-friendly crafting recipe
- Lightweight visual effects for mobile PojavLauncher use

## Build

The project will use Java 21 and Fabric Loom. A downloadable mod JAR will be provided after the source compiles and is tested in GitHub Actions.
